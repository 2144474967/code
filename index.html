Project Profile

智控灯--非侵入式人体+光照双感应wifi智能开关控制器
本项目基于ESP32开发免布线外置智能开关，依托芯片自建网页实现无线控制，搭配超声波+光敏双传感器，舵机机械按压原有墙面开关，无需改动室内电路。采用三级优先级控制逻辑，网页手动操控优先级最高并可短时锁定自动功能；昏暗且有人靠近自动开灯，无人活动5分钟自动关灯，通过光敏只控开灯的算法解决灯光自闪、误熄灯问题，3D打印外壳粘贴安装，适配宿舍、租房、独居老人等场景。

负责项目软硬件联调，调试ESP32网页服务与传感器驱动代码，逐项验证远程操控、感应启停、定时自锁功能，排查传感误触发、舵机动作异常等故障，保障整机逻辑稳定可靠。

Design Log - 设计迭代时间轴

Saturday Morning - 周六上午

设计方案并分工：小组成员讨论确定项目方向，明确各人职责分工。

初始方案

以 ESP32 DevKit NodeMCU 作为主控核心，搭载 HC-SR04 超声波传感器与光敏电阻分别采集人体动向和环境光照数据，利用 SG90 舵机模拟人手按压原有墙面物理开关，整机配套定制 3D 打印一体化外壳，依托 3M 双面胶粘贴在原有开关侧边，采用 USB-TYPE-C 低压供电，无需拆装原有线路，五分钟即可完成贴装、实现即贴即用；设备搭载独创的三级优先级、状态锁存与单向触发控制逻辑，其中优先级最高为手动控制，可通过 Blinker 手机 APP 远程操控或是设备本地按键启停开关，触发后自动锁定自动控制逻辑十分钟，防止自动程序干预人为操作；次优先级为自动开灯，在未处于手动锁定前提下，环境光线昏暗且超声波探测两米内有人体靠近时，舵机执行动作点亮灯具；末级为自动关灯，非锁定状态下传感器连续五分钟检测不到人体活动便自动关停灯光，系统还设定光敏仅参与开灯判定、不介入关灯逻辑的单向规则，既从源头杜绝灯具自身光源干扰光敏引发的误触发与灯光频闪问题，又能依靠人体活动实时刷新关灯倒计时，有效解决人在室内却无故熄灯的使用痛点。

Saturday Afternoon - 周六下午

初步实现方案：基于 ESP32 DevKit NodeMCU 开发，搭载 HC-SR04 超声波传感器与光敏电阻，使用 Blinker APP 进行远程控制，SG90 舵机按压墙面开关。

遇到的问题

问题 1：加入 Blinker 模块后编译速度很慢，其控制过程复杂
方案调整：放弃 Blinker APP，改用 ESP32 自建网页实现无线控制
问题 2：ESP32 DevKit NodeMCU 芯片所需的数据线难以寻找
方案调整：更换为 ESP32 LOLIN S2 Mini 芯片，采用 Type-C 接口

最终方案

基于 ESP32 开发免布线外置智能开关，依托芯片自建网页实现无线控制，搭配超声波 + 光敏双传感器，舵机机械按压原有墙面开关，无需改动室内电路。采用三级优先级控制逻辑，网页手动操控优先级最高并可短时锁定自动功能；昏暗且有人靠近自动开灯，无人活动 5 分钟自动关灯，通过光敏只控开灯的算法解决灯光自闪、误熄灯问题，3D 打印外壳粘贴安装，适配宿舍、租房、独居老人等场景。

超声波测距

float getDistance() { digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2); digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN, LOW); long duration = pulseIn(ECHO_PIN, HIGH, 30000); if (duration == 0) return 999; return duration * 0.034 / 2; }

舵机开灯/关灯

void turnOnLight() { if (!lightState) { servo.write(ON_ANGLE); // 舵机旋转按压开关 delay(500); servo.write(OFF_ANGLE); // 舵机回中 lightState = true; } } void turnOffLight() { if (lightState) { servo.write(ON_ANGLE); delay(500); servo.write(OFF_ANGLE); lightState = false; } }

自动控制主循环

void loop() { server.handleClient(); if (autoMode) { currentDistance = getDistance(); currentLight = readLightStable(); // 自动开灯：有人 + 光线暗 + 灯关闭 if (currentDistance < DETECT_DISTANCE) { lastHumanTime = millis(); if (currentLight < LIGHT_THRESHOLD && !lightState) { turnOnLight(); } } // 自动关灯：无人超过延时 + 灯开启 if (millis() - lastHumanTime > AUTO_OFF_DELAY && lightState) { turnOffLight(); } } delay(500); }

网页控制面板生成

void handleRoot() { String html = "<!DOCTYPE html><html>..."; // 模式切换按钮 if (autoMode) { html += "<button onclick='/setManual'>切换为手动</button>"; } else { html += "<button onclick='/setAuto'>切换为自动</button>"; } // 灯光控制按钮（自动模式下禁用） // 实时状态：距离、光照、灯状态 server.send(200, "text/html", html); }

Reflections - 反思与总结

遇到的硬核 Bug

Bug #1：舵机可旋转角度受限，无法往两边旋转
SG90 舵机实际控制中只能在 0°~90° 范围内旋转，无法向两侧（即 0° 以下或 90° 以上）继续偏转。墙面开关需要舵机臂向左右两个方向拨动才能实现开/关，单侧 90° 的行程不够覆盖开关的完整动作幅度，导致舵机无法可靠地完成"按下"和"弹起"两个状态的切换。
Bug #2：装置与开关难以连接
装置与墙面开关之间难以实现稳定连接，舵机臂无法有效按压开关。

解决方案与妥协

针对 Bug #1：
将舵机初始角度设置为 45°，以此为中位点，向左可旋转至 0°、向右可旋转至 90°，从而让舵机臂具备向两侧拨动的行程，完整覆盖开关的"开"和"关"两个状态。仅通过代码层面的角度偏移调整，无需改动硬件结构，便解决了单侧旋转不足的问题。
针对 Bug #2：
妥协方案：降低部分美观性，将舵机直接粘贴在开关旁边完成连接。

整体反思

收获：这次项目让我深刻体会到"从代码到实物"的过程中，硬件调试远比软件编程更具挑战性。在软硬件联调中，我学会了如何排查传感器误触发、舵机动作异常等实际问题，也掌握了 ESP32 网页服务与传感器驱动的配合调试方法。方案迭代的过程让我认识到，工程设计没有一步到位的完美方案，遇到问题及时调整、快速验证才是关键。

教训：前期选型时没有充分验证硬件兼容性，导致后期被迫更换芯片（DevKit → LOLIN S2 Mini）和控制方式（Blinker APP → 自建网页），浪费了宝贵的时间。舵机角度和力度的问题也提醒我，在动手搭建前应该先做小规模验证，而不是等到整机组装完毕才发现根本性问题。

如果重新来：会先用面包板搭建最小可行原型，逐一验证传感器灵敏度、舵机行程和力度是否满足需求，确认硬件可行后再进行 3D 打印外壳和整体组装，避免后期因硬件问题推翻重来。
